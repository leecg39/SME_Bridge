# 12. 제품 완성도 강화 리서치

작성일: 2026-05-31

## 제품 본연 기능

승계브릿지는 200억원 이하 중소기업 대표가 기업승계형 M&A를 처음 판단할 때 필요한 네 가지 질문을 빠르게 정리하는 제품이다.

1. 우리 회사의 예상 기업가치 범위는 얼마인가
2. 매각, 상속, 증여특례별 세금 차이는 무엇인가
3. 단계별로 어떤 자료와 결정을 준비해야 하는가
4. 어떤 상담 이슈를 전문가와 Patasos로 넘겨야 하는가

## 1차 A/B 테스트 기준

비교 대상은 세금 시뮬레이션이다.

- A안: 기존 화면의 시나리오별 고정 평균세율
- B안: 법령 구조와 계산 근거를 분리한 규칙 기반 계산
- 성공 기준: 같은 입력에서 B안이 출처 기반 계산식, 법령 기준일, 확인요건을 함께 제공하고 단위 테스트로 재현 가능해야 한다.

| 입력 | A안 결과 | B안 결과 | 판정 |
| --- | ---: | ---: | --- |
| 매각가 45억원, 지분율 100%, 증여특례 | 세액 7.6억원, 고정 16.9% | 세액 3.5억원, 10억원 공제 후 10% | B안이 국세청 특례 구조를 설명 가능 |
| 매각가 90억원, 지분율 100%, 증여특례 | 세액 15.2억원, 고정 16.9% | 세액 10억원, 60억원 초과분 20% | B안이 구간 계산을 재현 |
| 매각가 45억원, 지분율 100%, 상속세 | 세액 14.5억원, 고정 32.2% | 세액 17.9억원, 기본 누진세율 | B안이 공제 미반영 보수 시나리오임을 명시 |

## 기능 업그레이드 결정

1차 반영 대상은 세금 시뮬레이션이다.

- 계산 로직을 `frontend/src/lib/tax.ts`로 분리한다.
- 화면에는 실효세율, 계산 근거, 법령 기준일, 확인 필요 요건을 표시한다.
- `frontend/src/lib/tax.test.ts`에서 증여특례 공제/구간 계산과 혼합 전략을 검증한다.

## 후속 후보

- 로드맵에 기업승계 M&A 컨설팅 지원사업 자격 체크 추가
- 상담 요청에 정부지원 대상 여부 스냅샷 포함
- 가치평가 결과에 “정부지원 신청 가능 단계” 배지 추가
- 세금 시뮬레이션에 취득가액/보유기간/가업승계 요건 체크리스트 추가

## 2차 A/B 테스트 기준

비교 대상은 매각 로드맵의 Phase 1 준비 단계다.

- A안: 재무제표, 임대차 계약서, 거래처 비중 등 거래 준비 자료만 안내한다.
- B안: 첫 작업으로 `기업승계 M&A 컨설팅 지원사업 자격 확인`을 추가하고, 대표자 연령·업력·중소기업 여부·교섭 대상 유무로 기초컨설팅/종합컨설팅 연결 방향을 판정한다.
- 성공 기준: B안이 2026년 기업승계 M&A 컨설팅 지원사업의 매도희망기업 기본조건을 테스트로 재현하고, 프론트/백엔드 로드맵 기본 데이터가 같은 첫 작업을 제공해야 한다.

| 입력 | A안 결과 | B안 결과 | 판정 |
| --- | --- | --- | --- |
| 대표 63세, 업력 12년, 중소기업, 교섭 대상 없음 | 지원사업 여부를 알 수 없음 | 기초컨설팅 연결 | B안이 초기 상담 경로를 줄임 |
| 대표 57세, 업력 8년, 중소기업, 교섭 대상 있음 | 지원사업 여부를 알 수 없음 | 종합컨설팅 연결 | B안이 실사/가치평가 단계와 연결 |
| 대표 51세, 업력 3년, 중소기업 아님 | 지원사업 여부를 알 수 없음 | 미충족 조건 3개 표시 | B안이 부적합 사유를 명확화 |

## 2차 기능 업그레이드 결정

- `frontend/src/lib/government-support.ts`에 2026년 기업승계 M&A 컨설팅 지원사업의 기본 자격 판정 로직을 분리한다.
- `frontend/src/lib/mna-documents.ts`, `backend/app/services/mna_document_service.py`, `supabase/migrations/004_add_mna_phase_documents.sql`의 Phase 1 첫 작업을 동일하게 맞춘다.
- 프론트 단위 테스트와 백엔드 API 테스트로 자격 판정 및 로드맵 기본 데이터 일치를 검증한다.
