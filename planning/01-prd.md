## 1. 개요

### 1.1 배경

한국 중소기업의 고령화가 급속히 진행되고 있다. 중소벤처기업부 통계에 따르면 60대 이상 CEO가 운영하는 중소기업은 전체의 약 30%를 넘어섰으며, 이 중 상당수가 자녀 승계 의사가 없거나 후계자를 찾지 못한 상태다. 이들 기업은 적절한 매각 시점을 놓치면 폐업으로 이어지며, 축적된 기술력과 고용이 소멸된다.

기존 M&A 시장은 대형 딜(수백억~수천억) 중심으로 구성되어 있어, 매출 50억~200억 규모의 스몰딜 기업에 대한 전문 서비스가 부족하다. 고령 CEO들은 M&A 프로세스 자체에 대한 이해가 낮고, "우리 회사가 얼마나 되는지", "세금은 얼마나 나오는지", "무엇부터 준비해야 하는지"라는 가장 기본적인 질문에 대한 답을 구하기 어렵다.

### 1.2 문제 정의

| 문제 | 현황 | 영향 |
|------|------|------|
| 기업가치 파악 불가 | CEO가 자사의 객관적 가치를 모름 | 매각 의사결정 지연, 비합리적 가격 기대 |
| 세금 전략 부재 | 양도세/상속세/증여특례 등 복잡한 세제 이해 부족 | 수억 원 단위의 세금 손실 가능 |
| 프로세스 무지 | M&A 절차를 모르므로 무엇부터 시작해야 할지 모름 | 준비 없이 자문사 의존, 정보 비대칭 |
| 전문가 접근성 부족 | 스몰딜 전문 자문사를 찾기 어려움 | 대형 IB에 거절당하거나 과도한 수수료 부담 |

### 1.3 솔루션 개요

**승계브릿지**는 기업승계를 고민하는 중소기업 CEO가 자사의 가치를 파악하고, 세금 전략을 수립하며, 체계적인 매각 준비를 할 수 있도록 지원하는 플랫폼이다.

MVP 단계에서는 **매각을 고민하는 고령 CEO(60대+)**를 핵심 사용자로 설정하고, 기업가치 산정 -> 세금 시뮬레이션 -> 매각 로드맵 -> 전문가 연결이라는 핵심 플로우를 제공한다.

장기적으로는 CEO, M&A 자문사, 인수 후보자를 아우르는 **통합 플랫폼**으로 확장한다.

## 3. 페르소나

### 3.1 1차 페르소나 (MVP 핵심)

**김영호 대표 (가명, 67세)**

| 항목 | 내용 |
|------|------|
| **연령/성별** | 67세 남성 |
| **직함** | (주)동양정밀 대표이사 |
| **업종** | 자동차 부품 제조 (2차 협력사) |
| **매출 규모** | 연 매출 80억, 영업이익 8억 |
| **임직원** | 45명 |
| **CEO 경력** | 창업 32년차, 기술 출신 |
| **가족 상황** | 자녀 2명 (의사, 해외 거주) - 승계 의사 없음 |
| **IT 숙련도** | 낮음. 카카오톡, 네이버 검색 수준. 엑셀 기본 사용 가능 |
| **핵심 고민** | "내가 은퇴하면 이 회사는 어떻게 되나", "회사 팔면 세금이 얼마나 나오나" |
| **행동 특성** | 신중함, 대면 상담 선호, 숫자에 민감, 신뢰 기반 의사결정 |
| **기대** | 복잡한 것 없이 간단하게 회사 가치와 세금을 알고 싶음 |
| **두려움** | 정보 유출, 직원들이 알까봐 걱정, 사기 당할까봐 걱정 |

**김 대표의 하루:**
- 아침 7시 출근, 생산 현장 점검
- 오전: 거래처 미팅, 품질 이슈 처리
- 점심: 사업 관련 지인과 식사
- 오후: 서류 업무, 결재
- 저녁: 퇴근 후 TV 시청, 가끔 스마트폰으로 뉴스 검색
- 주말: 골프, 동종업계 모임

**Pain Points:**
1. 주변에 회사를 판 사람이 없어 정보가 없다
2. 자문사에 문의하면 바로 수수료 계약을 요구한다
3. "우리 회사가 얼마인지" 감도 잡히지 않는다
4. 인터넷 검색으로는 스몰딜 정보를 찾기 어렵다
5. 세무사에게 물어봐도 M&A 전문이 아니라 정확한 답을 못 준다

### 3.2 2차 페르소나 (향후 확장)

**박지은 이사 (가명, 42세) - M&A 자문사**

| 항목 | 내용 |
|------|------|

| **관심사** | 양질의 매각 딜소싱, 효율적인 매물 관리 |
| **Pain Point** | 스몰딜 매물 발굴이 어렵고, CEO 설득에 시간이 오래 걸림 |

**이준혁 상무 (가명, 50세) - 인수 후보자**

| 항목 | 내용 |
|------|------|
| **직함** | 중견기업 사업개발 담당 |
| **관심사** | 시너지 높은 인수 타깃 탐색, 적정 가격 판단 |
| **Pain Point** | 스몰딜 매물 정보가 체계적으로 정리되어 있지 않음 |

## 4. 핵심 기능 상세

### FEAT-1: 예상 기업가치 산정

**목적**: CEO가 자사의 객관적 예상 매각가를 파악할 수 있도록 한다.

#### 4.1.1 기능 흐름

```
[재무제표 업로드] → [AI 자동 추출] → [CEO 검토/수정] → [EBITDA 정상화] → [멀티플 기반 예상가 산출] → [결과 리포트]
```

#### 4.1.2 세부 요구사항

| ID | 요구사항 | 우선순위 | 설명 |
|----|----------|----------|------|
| F1.1 | 재무제표 업로드 | Must | PDF, 이미지(JPG/PNG), 엑셀 형식 지원. 최근 3개년 손익계산서, 재무상태표 |
| F1.2 | AI 자동 추출 | Must | OCR + LLM 기반 재무제표 항목 자동 인식 및 구조화 |
| F1.3 | 간이 입력 폼 | Must | AI 파싱 실패 시 또는 재무제표가 없는 CEO를 위한 수동 입력 폼. 매출, 영업이익, 감가상각비, 임원보수 등 핵심 항목만 |
| F1.4 | CEO 검토/수정 | Must | AI가 추출한 수치를 CEO가 확인하고 수정할 수 있는 화면. 원본과 나란히 비교 표시 |
| F1.5 | EBITDA 정상화 | Must | 오너 급여, 일회성 비용, 특수관계자 거래 등을 조정하여 정상화 EBITDA 산출 |
| F1.6 | 멀티플 적용 | Must | 업종별 EV/EBITDA 멀티플 적용. 보수적/중립/낙관 3가지 시나리오 |
| F1.7 | 결과 리포트 | Must | 예상 기업가치 범위를 시각적으로 표시. PDF 다운로드 가능 |
| F1.8 | 수동 검토 요청 | Should | 파싱 결과에 확신이 없을 때 전문가 수동 검토 요청 버튼 |

#### 4.1.3 멀티플 데이터 소스

- 한국거래소 업종별 평균 멀티플
- 중소기업 M&A 거래 사례 (공개 데이터)
- 자체 축적 거래 데이터 (장기)

#### 4.1.4 정상화 조정 항목

| 조정 항목 | 설명 | 예시 |
|-----------|------|------|
| 오너 초과 급여 | 시장 수준 대비 초과 보수 | 오너 연봉 3억 -> 시장 수준 1.5억 = +1.5억 조정 |
| 일회성 비용 | 반복되지 않는 비용 제거 | 소송비, 이사비용 등 |
| 특수관계자 거래 | 시장가 기준 조정 | 가족 임원 급여, 관계사 거래 |
| 비영업 자산/부채 | 사업 무관 항목 분리 | 유휴 부동산, 개인 차량 |
| 감가상각 정상화 | 세무 목적 과다/과소 상각 조정 | 실제 내용연수 기준 재계산 |

#### 4.1.5 UI/UX 고려사항

- 대형 폰트 (최소 16px, 핵심 수치 24px+)
- 단계별 마법사(Wizard) 형태 - 한 화면에 하나의 작업만
- 전문 용어에는 물음표 아이콘으로 쉬운 설명 툴팁 제공
- 진행률 표시바로 현재 단계 안내
- "잘 모르겠으면 건너뛰기" 옵션 제공

### FEAT-2: 세금 시뮬레이션

**목적**: 매각 시 발생하는 세금을 시나리오별로 비교하여 최적 전략을 파악한다.

#### 4.2.1 기능 흐름

```
[FEAT-1 결과 연동] → [CEO 추가 정보 입력] → [4가지 시나리오 자동 계산] → [시나리오 비교] → [최적 전략 제안]
```

#### 4.2.2 시나리오 유형

| 시나리오 | 설명 | 핵심 변수 |
|----------|------|-----------|
| A. 양도소득세 | 주식 양도 시 양도세 | 취득가액, 보유기간, 대주주 여부, 중소기업 특례 |
| B. 상속세 | 사후 상속 시 세금 | 상속재산 평가액, 공제항목, 가업상속공제 적용 여부 |
| C. 증여특례 | 생전 증여 후 매각 | 가업승계 증여특례(100억 한도), 5년 사후관리 요건 |
| D. 하이브리드 | 일부 증여 + 일부 양도 혼합 | 최적 비율 자동 산출 |

#### 4.2.3 세부 요구사항

| ID | 요구사항 | 우선순위 | 설명 |
|----|----------|----------|------|
| F2.1 | CEO 추가 정보 입력 | Must | 지분율, 취득가액, 보유기간, 가족관계, 중소기업 해당 여부 |
| F2.2 | 양도세 계산 | Must | 비상장주식 양도소득세 자동 계산 (세율, 공제 반영) |
| F2.3 | 상속세 계산 | Must | 상속세 예상액 계산 (가업상속공제 포함/미포함) |
| F2.4 | 증여특례 계산 | Must | 가업승계 증여특례 적용 시 세금 계산 |
| F2.5 | 하이브리드 시나리오 | Should | 양도 + 증여 혼합 시 최적 비율 자동 산출 |
| F2.6 | 시나리오 비교 차트 | Must | 4가지 시나리오를 한눈에 비교할 수 있는 바 차트 |
| F2.7 | 절세 효과 표시 | Must | 최적 시나리오 대비 절세 금액 강조 표시 |
| F2.8 | 법령 기준일 표시 | Must | 적용된 세법 기준일 명시 (세법 변경 리스크 고지) |
| F2.9 | 면책 고지 | Must | "본 시뮬레이션은 참고용이며, 정확한 세금은 전문가 상담 필요" 고지 |

#### 4.2.4 UI/UX 고려사항

- 시나리오별 세금 금액을 큰 숫자로 표시 (억 단위)
- 색상 코딩: 세금이 적은 시나리오일수록 초록색 강조
- "이 결과로 전문가와 상담하기" 버튼 상시 노출 (FEAT-4 연결)
- 입력 항목에 "우리 회사가 해당되나요?" 자가진단 가이드

### FEAT-3: 매각 로드맵

**목적**: M&A 프로세스 전체를 시각화하고, CEO가 단계별로 무엇을 준비해야 하는지 안내한다.

#### 4.3.1 로드맵 구성

| Phase | 단계명 | 예상 기간 | 핵심 활동 |
|-------|--------|-----------|-----------|
| Phase 1 | 매각 준비 | 3~6개월 | 재무 정비, 법률 검토, 기업가치 산정 |
| Phase 2 | 마케팅 | 2~3개월 | IM(정보메모) 작성, 인수후보 탐색 |
| Phase 3 | 실사(DD) | 1~2개월 | 재무/법률/세무/기술 실사 |
| Phase 4 | 협상/계약 | 1~2개월 | 가격 협상, SPA(주식매매계약) 체결 |
| Phase 5 | 클로징/PMI | 1~3개월 | 대금 수수, 경영권 이전, 인수 후 통합 |

#### 4.3.2 세부 요구사항

| ID | 요구사항 | 우선순위 | 설명 |
|----|----------|----------|------|
| F3.1 | 칸반보드 뷰 | Must | 5개 Phase를 칸반보드 형태로 시각화 |
| F3.2 | Phase별 체크리스트 | Must | 각 Phase에서 CEO가 준비해야 할 항목 목록 |
| F3.3 | 체크리스트 완료 체크 | Must | 항목별 완료/미완료 체크 기능 |
| F3.4 | 템플릿 제공 | Should | NDA, LOI, 체크리스트 등 문서 템플릿 다운로드 |
| F3.5 | 진행률 표시 | Must | 전체 매각 준비 진행률(%) 시각화 |
| F3.6 | 예상 일정 표시 | Should | 각 Phase의 예상 소요 기간 표시 |
| F3.7 | 알림/리마인더 | Could | 다음 해야 할 일 카카오톡/SMS 알림 |

#### 4.3.3 Phase 1 체크리스트 예시

```
Phase 1: 매각 준비
  [ ] 최근 3개년 감사보고서 준비
  [ ] 임대차 계약서 정리
  [ ] 주요 거래처 계약서 정리
  [ ] 특허/인증 목록 작성
  [ ] 핵심 인력 목록 및 고용 조건 정리
  [ ] 소송/분쟁 이력 확인
  [ ] 환경/안전 인허가 현황 정리
  [ ] CEO 개인 자산과 회사 자산 분리
```

#### 4.3.4 UI/UX 고려사항

- 현재 Phase를 시각적으로 강조 (나머지는 흐리게)
- 체크 완료 시 만족감을 주는 애니메이션
- "다음에 해야 할 일" 상단 고정 배너
- 전체 로드맵을 한 페이지에서 조망 가능

## 5. 사용자 시나리오

### 5.1 핵심 시나리오: 김영호 대표의 첫 방문

**트리거**: 김 대표는 동종업계 모임에서 "요즘 회사 매각하는 사람이 많다"는 이야기를 듣고, 네이버에서 "중소기업 매각 방법"을 검색한다. 검색 결과에서 승계브릿지 광고를 클릭한다.

**시나리오 흐름:**

```
1. 랜딩페이지 도착
   - "우리 회사, 얼마에 팔 수 있을까?" 헤드라인
   - "3분 만에 예상 기업가치를 확인하세요" 서브 헤드라인
   - [무료로 기업가치 확인하기] 버튼

2. 회원가입 (간소화)
   - 휴대폰 번호 인증만으로 가입
   - 이름, 회사명, 업종, 매출 규모 (선택형)
   - 비밀번호 설정

3. FEAT-1: 기업가치 산정
   3-1. 입력 방식 선택
        "재무제표를 업로드하시겠습니까?"
        [파일 업로드] / [직접 입력할게요]

   3-2a. (업로드 선택 시) PDF 업로드
        - 손익계산서, 재무상태표 업로드
        - AI가 자동으로 수치 추출 (로딩 화면: "분석 중입니다...")
        - 추출 결과 확인 화면: "이 숫자가 맞나요?"
        - CEO가 확인/수정 후 [확인] 버튼

   3-2b. (직접 입력 선택 시) 간이 입력 폼
        - 최근 3년 매출, 영업이익
        - 감가상각비 (모르면 건너뛰기)
        - 대표이사 급여 (정상화 조정용)

   3-3. EBITDA 정상화
        - "대표님 급여가 연 2.5억이시군요. 시장 수준(1.2억)보다 높아
          이 차이를 기업가치에 반영합니다."
        - 조정 항목별 쉬운 설명 + 적용/미적용 토글

   3-4. 결과 확인
        - "귀사의 예상 기업가치는 40억 ~ 56억입니다"
        - 보수적/중립/낙관 3가지 시나리오 바 차트
        - "동종 업계 평균 대비 상위 30%" 안내
        - [세금을 확인해볼까요?] [리포트 PDF 다운로드]

4. FEAT-2: 세금 시뮬레이션
   4-1. 추가 정보 입력
        - 지분율 (100%), 주식 취득가액 (1억), 보유기간 (32년)
        - 가족관계: 자녀 2명 (승계 의사 없음)

   4-2. 시나리오 비교
        - A. 양도세: 약 6.2억
        - B. 상속세 (현재 사망 시): 약 12.8억
        - C. 증여특례: 해당 없음 (자녀 승계 불가)
        - D. 하이브리드: 해당 없음
        → 최적 전략: "양도(매각)가 세금 측면에서 유리합니다"

   4-3. [전문가에게 정확한 세금 상담 받기] 버튼

5. FEAT-3: 매각 로드맵
   - Phase 1~5 칸반보드 표시
   - "대표님은 현재 Phase 1 (매각 준비) 단계입니다"
   - 첫 번째 할 일: "최근 3개년 감사보고서를 준비해주세요"
   - 체크 완료 시 다음 할 일 안내

6. FEAT-4: 전문가 연결
   - [M&A 전문 자문사와 상담하기] 버튼 클릭
   - 간단 폼: 희망 상담 시간, 궁금한 점
   - "24시간 내에 전문가가 연락드립니다" 안내
```

### 5.2 보조 시나리오: 재방문 (3일 후)

```
1. 로그인
2. 대시보드
   - "지난번 산정하신 기업가치: 40억~56억"
   - "매각 준비 진행률: 15%"
   - "다음 할 일: 임대차 계약서 정리"
   - "OO 자문사에서 연락이 올 예정입니다"
3. 체크리스트에서 완료 항목 체크
4. 필요 시 기업가치 재산정 (수치 업데이트)
```

### 5.3 보조 시나리오: 자녀와 함께 확인

```
1. CEO가 자녀에게 링크 공유
2. 자녀가 리포트 열람 (열람 전용)
   - 기업가치 산정 결과
   - 세금 시뮬레이션 비교
   - 매각 로드맵 현황
3. 자녀가 전문가 상담에 동석 요청 가능
```

| **약점** | 자문사(B2B) 대상이라 CEO 직접 사용 어려움, 스몰딜 특화 아님 |

## 9. 성공 지표

### 9.1 노스스타 메트릭

> **월간 기업가치 산정 완료 건수**

이 지표를 선택한 이유:
- CEO가 기업가치 산정을 완료한다는 것은 핵심 가치를 경험했다는 의미
- 산정 완료 후 세금 시뮬레이션, 로드맵, 전문가 연결로의 전환이 자연스럽게 발생
- 측정이 명확하고, 조작이 어려움

### 9.2 입력 지표 (Leading Indicators)

| 지표 | 정의 | 목표 (런칭 후 6개월) |
|------|------|----------------------|
| 회원가입 전환율 | 랜딩페이지 방문 -> 회원가입 완료 | 15% |
| 재무제표 업로드율 | 가입 -> 재무제표 업로드(또는 직접입력) 완료 | 60% |
| 산정 완료율 | 업로드 -> 기업가치 산정 완료 | 80% |
| 세금 시뮬레이션 전환율 | 기업가치 산정 완료 -> 세금 시뮬레이션 실행 | 50% |
| 전문가 상담 요청율 | 세금 시뮬레이션 완료 -> 전문가 상담 요청 | 30% |

### 9.3 결과 지표 (Lagging Indicators)

| 지표 | 정의 | 목표 (런칭 후 12개월) |
|------|------|----------------------|
| 월간 활성 사용자 (MAU) | 월 1회 이상 로그인 | 500명 |
| 전문가 상담 성사율 | 상담 요청 -> 실제 상담 진행 | 70% |
| 자문 계약 전환율 | 상담 -> 자문 계약 체결 | 20% |
| NPS | 순추천지수 | 40 이상 |
| 7일 리텐션 | 가입 후 7일 내 재방문 | 30% |

### 9.4 가드레일 지표 (Guardrail Metrics)

| 지표 | 설명 | 임계값 |
|------|------|--------|
| AI 파싱 정확도 | 재무제표 항목 추출 정확도 | 90% 미만 시 경보 |
| 세금 계산 오차율 | 전문가 검증 대비 오차 | 10% 이상 시 경보 |
| 페이지 로드 시간 | P95 기준 | 5초 초과 시 경보 |
| 이탈율 | 기업가치 산정 중간 이탈 | 50% 초과 시 원인 분석 |

| # | 리스크 | 영향도 | 발생 확률 | 완화 전략 |
|---|--------|--------|-----------|-----------|

| R10 | AI 파싱 오류로 인한 잘못된 기업가치 제시 | 높음 | 중 | "참고용" 면책 고지, CEO 확인 단계 필수, 수동 검토 옵션 |

### 11.4 Top 리스크 상세: 재무제표 AI 파싱 정확도 (R1)

이 리스크가 가장 중요한 이유:
- 기업가치 산정의 입력 데이터 품질이 전체 서비스 신뢰도를 결정
- 60대 CEO가 직접 수치를 검증하기 어려울 수 있음
- 중소기업 재무제표 형식이 다양하여 표준화 어려움

**완화 실험 계획:**

| 실험 | 기간 | 성공 기준 |
|------|------|-----------|
| OCR + LLM 파싱 정확도 측정 (100건 샘플) | 4주 | 항목별 정확도 90% 이상 |
| 간이 입력 폼 사용성 테스트 (CEO 10명) | 2주 | 완료율 80% 이상 |
| AI 파싱 + 수동 검토 병행 운영 비용 분석 | 2주 | 건당 수동 검토 비용 5만원 이하 |
| CEO 검토/수정 화면 사용성 테스트 | 2주 | CEO가 오류를 발견하고 수정할 수 있는 비율 70% 이상 |

## 부록

### A. 용어 정의

| 용어 | 정의 |
|------|------|
| EBITDA | Earnings Before Interest, Taxes, Depreciation and Amortization. 이자, 세금, 감가상각비 차감 전 이익. 기업의 영업 현금 창출 능력을 나타냄 |
| 멀티플 (Multiple) | 기업가치를 산정할 때 EBITDA 등 재무지표에 곱하는 배수. 업종/규모에 따라 다름 (예: EV/EBITDA 5x = EBITDA의 5배가 기업가치) |
| EV (Enterprise Value) | 기업가치. 시가총액 + 순차입금. 기업 전체의 경제적 가치 |
| DD (Due Diligence) | 실사. 인수 전 기업의 재무, 법률, 세무, 기술 등을 종합 조사하는 과정 |
| SPA | Share Purchase Agreement. 주식매매계약서 |
| LOI | Letter of Intent. 인수의향서 |
| IM (Information Memorandum) | 투자정보요약서. 잠재 인수자에게 제공하는 기업 소개 자료 |
| PMI | Post-Merger Integration. 인수 후 통합. 기업 인수 완료 후 조직/시스템/문화 통합 과정 |
| NDA | Non-Disclosure Agreement. 비밀유지계약 |
| 정상화 (Normalization) | 일회성/비경상적 항목을 조정하여 기업의 실질 수익력을 파악하는 과정 |
