## 1. 개요

승계브릿지는 중소기업 CEO가 기업 매각(승계)을 준비하는 전 과정을 지원하는 플랫폼이다.
사용자는 재무제표 업로드부터 기업가치 산정, 세금 시뮬레이션, 매각 로드맵 관리까지
하나의 흐름 안에서 단계적으로 진행할 수 있다.

### 핵심 원칙

- **순차 진행**: 업로드 -> AI 검토 -> 결과 -> 세금 -> 로드맵 순서로 자연스럽게 유도
- **언제든 상담**: 전문가 상담은 모든 화면에서 플로팅 버튼으로 접근 가능
- **재방문 지원**: 대시보드에서 마지막 작업 지점으로 바로 이동 가능
- **단계 잠금**: 이전 단계 완료 전 다음 단계 접근 제한 (데이터 의존성)

## 4. 메인 시나리오 (Happy Path)

> CEO가 처음 방문하여 기업가치 산정부터 매각 로드맵까지 완료하는 이상적인 흐름

### 단계별 흐름

```
Step 1       Step 2        Step 3        Step 4        Step 5
랜딩 -------> 회원가입 ----> 대시보드 ----> 업로드 ------> AI 검토
  |            |              |             |              |
  | CTA 클릭   | 정보 입력     | 카드 클릭    | 파일 선택     | 수치 확인
  | "시작하기"  | CEO 인증     | "가치 산정"  | 드래그앤드롭  | "확인" 클릭
  v            v              v             v              v

Step 6        Step 7        Step 8
결과 -------> 세금 --------> 로드맵
  |            |              |
  | CTA 클릭   | CTA 클릭     | 체크리스트
  | "세금 보기" | "로드맵"     | 작성 시작
  v            v              v
```

### Step 1: 랜딩 페이지 (/)

| 항목       | 내용                                              |
|------------|--------------------------------------------------|
| 진입 조건   | 없음 (공개 페이지)                                 |
| 사용자 행동 | 서비스 소개 확인 후 "무료로 시작하기" CTA 클릭        |
| 화면 요소   | 히어로 배너, 서비스 설명, 고객 후기, CTA 버튼        |
| 이동 경로   | CTA 클릭 -> /auth (회원가입)                       |
| 소요 시간   | 약 30초 ~ 2분                                     |

### Step 2: 회원가입/로그인 (/auth)

| 항목       | 내용                                              |
|------------|--------------------------------------------------|
| 진입 조건   | 랜딩 CTA 클릭 또는 직접 URL 접근                    |
| 사용자 행동 | 이메일/비밀번호 입력, CEO 본인 인증                  |
| 화면 요소   | 회원가입 폼, 로그인 탭, 소셜 로그인 옵션              |
| 이동 경로   | 인증 성공 -> /dashboard                            |
| 소요 시간   | 약 1 ~ 3분                                        |

### Step 3: 대시보드 (/dashboard)

| 항목       | 내용                                              |
|------------|--------------------------------------------------|
| 진입 조건   | 로그인 완료                                        |
| 사용자 행동 | 4개 요약 카드 확인, "기업가치 알아보기" 카드 클릭      |
| 화면 요소   | 가치 카드, 세금 카드, 로드맵 카드, 상담 카드          |
| 이동 경로   | 가치 카드 클릭 -> /valuation/upload                 |
| 소요 시간   | 약 10초 ~ 1분                                     |

### Step 4: 재무제표 업로드 (/valuation/upload)

| 항목       | 내용                                              |
|------------|--------------------------------------------------|
| 진입 조건   | 로그인 상태                                        |
| 사용자 행동 | 재무제표 파일(PDF/Excel) 드래그앤드롭 또는 파일 선택   |
| 화면 요소   | 업로드 영역, 파일 형식 안내, 샘플 다운로드             |
| 이동 경로   | 업로드 완료 -> /valuation/review (자동 이동)         |
| 소요 시간   | 약 30초 ~ 2분                                     |

### Step 5: AI 추출/검토 (/valuation/review)

| 항목       | 내용                                              |
|------------|--------------------------------------------------|
| 진입 조건   | 재무제표 업로드 완료                                 |
| 사용자 행동 | AI가 추출한 재무 수치 확인, 필요시 수정, "확인" 클릭   |
| 화면 요소   | 추출 수치 테이블, 수정 입력 필드, 원본 미리보기        |
| 이동 경로   | 확인 클릭 -> /valuation/result                      |
| 소요 시간   | 약 2 ~ 5분                                        |

### Step 6: 예상가치 결과 (/valuation/result)

| 항목       | 내용                                              |
|------------|--------------------------------------------------|
| 진입 조건   | AI 검토 확인 완료                                   |
| 사용자 행동 | EBITDA/멀티플 기반 예상가 확인, "세금 시뮬레이션" CTA  |
| 화면 요소   | 예상가 범위(최소/중간/최대), EBITDA 차트, 산업 비교    |
| 이동 경로   | CTA 클릭 -> /tax-simulation                        |
| 소요 시간   | 약 1 ~ 3분                                        |

### Step 7: 세금 시뮬레이션 (/tax-simulation)

| 항목       | 내용                                              |
|------------|--------------------------------------------------|
| 진입 조건   | 예상가치 결과 확인 완료                              |
| 사용자 행동 | 4가지 시나리오(양도, 합병, 증여, 상속) 비교 확인       |
| 화면 요소   | 시나리오 비교 표, 세금 차이 그래프, 절세 팁            |
| 이동 경로   | CTA 클릭 -> /roadmap                               |
| 소요 시간   | 약 3 ~ 5분                                        |

### Step 8: 매각 로드맵 (/roadmap)

| 항목       | 내용                                              |
|------------|--------------------------------------------------|
| 진입 조건   | 세금 시뮬레이션 완료 (또는 대시보드에서 직접 접근)      |
| 사용자 행동 | 칸반보드 확인, Phase별 체크리스트 진행, 템플릿 다운로드  |
| 화면 요소   | 칸반보드(준비/실행/완료), 체크리스트, 문서 템플릿       |
| 이동 경로   | 대시보드 -> /dashboard, 상담 -> /consultation        |
| 소요 시간   | 지속적 사용 (수 주 ~ 수 개월)                        |

## 5. 서브 시나리오

### 5.1 재방문 사용자

```
사용자가 이전에 가치 산정까지 완료한 상태에서 재방문

  [1] 랜딩
   |
   +---> [2] 로그인 (기존 계정)
          |
          +---> [3] 대시보드
                 |
                 |  가치 카드: "예상가 32억" (완료 표시)
                 |  세금 카드: "시뮬레이션 시작하기" (미완료)
                 |  로드맵 카드: "잠금" (이전 단계 미완료)
                 |
                 +---> [7] 세금 시뮬레이션 (마지막 작업 지점)
                        |
                        +---> (이후 메인 플로우 계속)
```

**대시보드 카드 상태 분기**:

| 카드          | 상태           | 클릭 시 이동              |
|--------------|---------------|--------------------------|
| 가치 카드     | 미완료 (신규)   | /valuation/upload        |
| 가치 카드     | 완료           | /valuation/result (결과)  |
| 세금 카드     | 미완료 (잠금)   | 토스트: "가치 산정 먼저"   |
| 세금 카드     | 미완료 (활성)   | /tax-simulation          |
| 세금 카드     | 완료           | /tax-simulation (결과)    |
| 로드맵 카드   | 미완료 (잠금)   | 토스트: "세금 시뮬 먼저"   |
| 로드맵 카드   | 미완료 (활성)   | /roadmap                 |
| 로드맵 카드   | 진행 중        | /roadmap (마지막 위치)    |
| 상담 카드     | 항상 활성       | /consultation            |

### 5.2 수치 수정 시나리오

```
CEO가 AI 추출 결과에서 수치 오류 발견

  [5] AI 추출/검토
   |
   +---> CEO가 매출액 수치 수정 (인라인 편집)
   |     - 수정 가능 필드: 매출액, 영업이익, 감가상각비, EBITDA 등
   |     - 수정 시 실시간 유효성 검사
   |
   +---> "수정 완료" 클릭
   |     - 변경 이력 저장
   |     - 수정된 수치 하이라이트 표시
   |
   +---> [6] 예상가치 결과 (수정 수치 반영)
```

```
CEO가 결과 확인 후 수치 재수정 원할 때

  [6] 예상가치 결과
   |
   +---> "수치 수정하기" 링크 클릭
   |
   +---> [5] AI 추출/검토 (기존 수치 + 수정 이력 표시)
          |
          +---> 재수정 후 "확인"
          |
          +---> [6] 예상가치 결과 (재계산)
```

### 5.3 재무제표 재업로드 시나리오

```
CEO가 다른 연도 재무제표로 교체하고 싶을 때

  [5] AI 추출/검토
   |
   +---> "다시 업로드" 버튼 클릭
   |
   +---> [4] 재무제표 업로드
   |      |
   |      +---> 기존 파일 삭제 확인 모달
   |      |     "기존 분석 결과가 초기화됩니다. 계속하시겠습니까?"
   |      |
   |      +---> [예] --> 새 파일 업로드 --> [5] AI 추출/검토 (새 데이터)
   |      +---> [아니오] --> [5] AI 추출/검토 (기존 유지)
   |
   v

  [6] 예상가치 결과
   |
   +---> "재무제표 변경" 링크
   |
   +---> [4] 재무제표 업로드 (동일 흐름)
```

### 5.4 전문가 상담 요청 시나리오

```
어느 화면에서든 전문가 상담 접근 가능

  [3]~[8] 어느 화면이든
   |
   +---> 플로팅 버튼 (FAB) 클릭
   |     또는 사이드바 "전문가 상담" 메뉴
   |
   +---> [9] 전문가 상담 요청 (/consultation)
          |
          |  폼 필드:
          |  - 상담 유형 (가치 평가 / 세금 / 법률 / 기타)
          |  - 연락처 (이름, 전화번호, 이메일)
          |  - 희망 일시
          |  - 간단한 문의 내용
          |  - 현재 진행 단계 (자동 기입)
          |
          +---> "상담 요청" 제출
          |     - 성공 토스트: "전문가가 24시간 내 연락드립니다"
          |

```

**상담 유형별 자동 추천 (컨텍스트 기반)**:

| /roadmap              | M&A 법률 전문가        |

```
        |     - 행동: 파일 선택 영역 유지, 재시도 가능
        |
        +---> [실패: 파일 크기 초과]
        |     - 에러 메시지: "파일 크기가 20MB를 초과합니다"
        |     - 행동: 파일 선택 영역 유지, 재시도 가능
        |
        +---> [실패: 네트워크 오류]
        |     - 에러 메시지: "업로드 중 오류가 발생했습니다. 다시 시도해주세요"
        |     - 행동: [다시 시도] 버튼 표시
        |
        +---> [실패: 서버 오류]
              - 에러 메시지: "일시적 오류입니다. 잠시 후 다시 시도해주세요"
              - 행동: [다시 시도] 버튼, 고객센터 연락 안내
```

### 7.2 AI 추출 실패 시나리오

```
[5] AI 추출/검토
 |
 +---> AI 분석 시도
        |
        +---> [실패: 인식 불가]
        |     - 에러: "재무제표를 인식할 수 없습니다"
        |     - 원인: 스캔 품질 불량, 비표준 양식
        |     - 행동: "다시 업로드" 안내 + 권장 파일 형식 안내
        |     - 이동: --> /valuation/upload
        |
        +---> [부분 성공: 데이터 부족]
        |     - 경고: "일부 항목을 추출하지 못했습니다"
        |     - 행동: 추출된 항목 표시 + 누락 항목 수동 입력 안내
        |     - 누락 필드 노란색 하이라이트 표시
        |     - CEO가 직접 입력 후 진행 가능
        |
        +---> [부분 성공: 낮은 신뢰도]
              - 경고: "AI 신뢰도가 낮습니다 (60%). 수치를 확인해주세요"
              - 행동: 신뢰도 낮은 항목 주황색 하이라이트
              - CEO 확인 후 진행 가능
```

### 7.3 인증 관련 예외

```
[인증 예외 처리]
 |
 +---> [세션 만료]
 |     - 상황: 로그인 후 장시간 미사용 (30분)
 |     - 처리: 로그인 모달 표시 (현재 페이지 유지)
 |     - 재로그인 후 동일 페이지로 복귀
 |
 +---> [비인가 접근]
 |     - 상황: 비로그인 상태에서 보호 페이지 접근
 |     - 처리: /auth로 리다이렉트
 |     - 리다이렉트 URL 파라미터 저장 (?redirect=/dashboard)
 |     - 로그인 성공 후 원래 접근하려던 페이지로 이동
 |
 +---> [중복 로그인]
 |     - 상황: 다른 기기에서 로그인
 |     - 처리: 기존 세션 유지 (최신 세션 우선 정책)
 |
 +---> [회원가입 실패]
       - 이메일 중복: "이미 가입된 이메일입니다. 로그인하시겠습니까?"
       - 인증 실패: "본인 인증에 실패했습니다. 다시 시도해주세요"
       - 비밀번호 규칙 미충족: 실시간 유효성 검사 피드백
```

### 7.4 데이터 의존성 예외

```
[단계 잠금 처리]

 +---> [세금 시뮬레이션 접근 시 가치 산정 미완료]

 +---> [로드맵 접근 시 세금 시뮬레이션 미완료]

 |       "세금 시뮬레이션을 먼저 완료해주세요"
 |     - 자동 이동: --> /tax-simulation

       - 처리: 메뉴 비활성 (회색) + 툴팁 표시
```

## 8. 화면 이동 매트릭스

### 8.1 이동 가능 여부 표

아래 표는 각 화면에서 다른 화면으로의 이동 가능 여부를 나타낸다.

```
출발 \ 도착    [1]   [2]   [3]   [4]   [5]   [6]   [7]   [8]   [9]
[1] 랜딩       -    직접    -     -     -     -     -     -     -
[2] 인증      뒤로   -    성공    -     -     -     -     -     -
[3] 대시보드    -   로그    -    카드  (조건) 카드  (조건) (조건) 카드
[4] 업로드      -    -    뒤로    -    완료    -     -     -    FAB
[5] AI검토      -    -    뒤로  재업     -    확인    -     -    FAB
[6] 결과        -    -    뒤로    -    수정    -    CTA    -    FAB
[7] 세금        -    -    뒤로    -     -    링크    -    CTA   FAB
[8] 로드맵      -    -    뒤로    -     -    링크  링크    -    FAB
[9] 상담        -    -    복귀    -     -     -     -     -     -
```

| 기호   | 의미                              |
|--------|----------------------------------|
| 직접   | 직접 이동 (CTA 버튼)               |
| 성공   | 인증 성공 시 자동 이동              |
| 카드   | 대시보드 카드 클릭                  |
| (조건) | 이전 단계 완료 조건 충족 시에만 이동  |
| 뒤로   | 뒤로가기/네비게이션                  |
| 완료   | 업로드 완료 시 자동 이동             |
| 확인   | 검토 확인 클릭 시                   |
| CTA    | Call To Action 버튼                |
| 수정   | "수치 수정하기" 링크                |
| 재업   | "다시 업로드" 버튼                  |
| 링크   | 텍스트 링크                        |
| FAB    | 플로팅 액션 버튼                    |
| 복귀   | 이전 화면 자동 복귀                  |
| 로그   | 로그아웃 시                        |

### 8.2 단계 잠금 조건

```
[4] 업로드        --> 잠금 없음 (언제든 접근 가능)
[5] AI 검토       --> [4] 업로드 완료 필요
[6] 예상가치 결과  --> [5] AI 검토 확인 완료 필요
[7] 세금 시뮬     --> [6] 예상가치 결과 생성 필요
[8] 로드맵        --> [7] 세금 시뮬레이션 완료 필요
[9] 전문가 상담   --> 잠금 없음 (언제든 접근 가능)
```
