## 1. 디자인 원칙

### 핵심 철학: "평생의 성과를 안심하고 맡길 수 있는 파트너"

60대 이상 CEO는 IT 서비스에 익숙하지 않지만 수십 년간 기업을 경영한 전문가입니다. 디자인은 그분들의 **경험과 판단을 존중**하고, **불필요한 학습 없이** 서비스를 사용할 수 있도록 설계되어야 합니다.

### 4가지 핵심 원칙

| 원칙 | 설명 | 적용 방향 |
|------|------|----------|
| **신뢰 우선 (Trust First)** | 금융·법률 수준의 신뢰감을 시각적으로 표현 | 네이비 중심 배색, 절제된 레이아웃, 과도한 장식 금지 |
| **명확한 가독성 (Clarity)** | 60대+ 사용자를 위한 큰 글씨와 강한 대비 | 본문 최소 18px, 색상 대비 WCAG AA 이상 |
| **단순한 흐름 (Simplicity)** | 한 화면에 하나의 핵심 행동만 요구 | 최대 클릭 3회로 목표 달성 가능하도록 설계 |
| **따뜻한 전문성 (Warm Professionalism)** | 차갑지 않고 신뢰할 수 있는 분위기 | 골드 포인트 컬러로 가치 강조, 부드러운 그림자 |

### 금지 사항

- 플래시 효과, 과도한 애니메이션 (10fps 이상 깜빡임 금지)
- 3개 이상의 배색 동시 사용 (강조색 포함 2개까지)
- 10px 이하 텍스트
- 아이콘만으로 기능 설명하기 (반드시 텍스트 레이블 병행)
- 팝업 과다 사용 (세션 당 최대 1회)

## 3. 타이포그래피

### 3.1 서체 선택

**주 서체: Pretendard (한글) + Georgia (영문 수치)**

Pretendard는 가독성이 뛰어난 고딕 계열 서체로, 60대 이상 사용자가 익숙한 명조풍 대비보다 화면에서의 선명도가 우수합니다. Georgia는 금액 및 영문 수치에 한해 신뢰감을 주는 세리프체로 사용합니다.

```css
/* 서체 스택 */
font-family-base: 'Pretendard', 'Apple SD Gothic Neo', '맑은 고딕', sans-serif;
font-family-numeric: 'Georgia', 'Times New Roman', serif;
```

### 3.2 타입 스케일

| 레벨 | 이름 | 크기 | 행간 | 자간 | 굵기 | 용도 |
|------|------|------|------|------|------|------|
| H1 | 페이지 제목 | 36px | 1.3 | -0.02em | 700 | 메인 페이지 제목, 랜딩 히어로 |
| H2 | 섹션 제목 | 28px | 1.35 | -0.01em | 700 | 대시보드 섹션, 모달 제목 |
| H3 | 카드 제목 | 22px | 1.4 | -0.01em | 600 | 카드 헤더, 테이블 그룹명 |
| H4 | 소제목 | 18px | 1.45 | 0em | 600 | 폼 그룹, 아코디언 헤더 |
| Body-L | 강조 본문 | 18px | 1.7 | 0em | 400 | 중요 설명, 안내 메시지 |
| Body | 기본 본문 | 16px | 1.7 | 0em | 400 | 일반 설명, 폼 레이블 |
| Body-S | 보조 본문 | 14px | 1.6 | 0.01em | 400 | 부연 설명, 날짜 |
| Caption | 캡션 | 12px | 1.5 | 0.02em | 400 | 법적 고지, 출처 표기 |
| Numeric-L | 대형 수치 | 32px | 1.2 | -0.02em | 700 | 기업 가치, 주요 금액 |
| Numeric | 기본 수치 | 20px | 1.4 | -0.01em | 600 | 재무 표 내 금액 |

> **60대+ 접근성 원칙:** 본문 최소 크기는 16px, 핵심 정보는 반드시 18px 이상 사용

### 3.3 텍스트 색상 조합 (대비 준수)

| 배경 | 텍스트 | 대비비 | WCAG 등급 |
|------|--------|--------|----------|
| White `#FFFFFF` | Neutral-900 `#1A1A2E` | 17.2:1 | AAA |
| Navy-050 `#F4F7FD` | Neutral-900 `#1A1A2E` | 16.1:1 | AAA |
| Navy-900 `#0F2044` | White `#FFFFFF` | 14.8:1 | AAA |
| Navy-100 `#E8EFFA` | Navy-800 `#1A3060` | 8.4:1 | AAA |
| Gold-100 `#FDF6DC` | Neutral-900 `#1A1A2E` | 14.3:1 | AAA |

## 4. 스페이싱 및 그리드 시스템

### 4.1 스페이싱 토큰 (8px 베이스 그리드)

```
space-1   4px   ← 아이콘 내부 간격, 뱃지 패딩
space-2   8px   ← 인접 요소 간 최소 간격
space-3   12px  ← 인풋 내부 패딩 (상하)
space-4   16px  ← 기본 컴포넌트 패딩, 카드 내부
space-5   20px  ← 폼 필드 간 간격
space-6   24px  ← 섹션 내 요소 간격
space-8   32px  ← 카드 간 간격
space-10  40px  ← 섹션 상단 여백
space-12  48px  ← 대형 섹션 구분
space-16  64px  ← 페이지 상단 패딩
space-20  80px  ← 히어로/랜딩 여백
```

### 4.2 터치/클릭 타겟 규격

| 대상 사용자 | 최소 타겟 크기 | 권장 타겟 크기 |
|------------|--------------|--------------|
| 일반 성인 | 44 x 44px | 48 x 48px |
| **60대+ (승계브릿지)** | **56 x 56px** | **64 x 64px** |

모든 버튼, 링크, 체크박스, 라디오 버튼은 최소 56px 높이를 유지합니다.

### 4.3 그리드 시스템

**데스크톱 (1280px 이상) — 12컬럼 그리드**

```
컨테이너 최대 너비: 1440px
좌우 여백 (padding): 64px
컬럼 개수: 12
컬럼 간격 (gutter): 24px
컬럼 너비: (1440 - 128 - 264) / 12 ≈ 87px
```

**태블릿 (768px ~ 1279px) — 8컬럼 그리드**

```
컨테이너: 100% - 48px 여백
좌우 여백 (padding): 32px
컬럼 개수: 8
컬럼 간격 (gutter): 20px
```

**레이아웃 패턴 (데스크톱 기준)**

```
┌─────────────────────────────────────────────┐
│  내비게이션 (고정, Navy-900 배경)             │
├──────────┬──────────────────────────────────┤
│          │                                  │
│  사이드바  │  메인 콘텐츠 영역                │
│  (3col)  │  (9col)                          │
│          │                                  │
│          │                                  │
└──────────┴──────────────────────────────────┘

카드 레이아웃:
- 1행 4카드: 각 3col (대시보드 KPI)
- 1행 3카드: 각 4col (일반 카드 목록)
- 1행 2카드: 각 6col (비교 레이아웃)
- 전체 너비: 12col (테이블, 상세 페이지)
```

### 4.4 레이어 및 그림자

```css
/* 그림자 토큰 */
shadow-sm:  0 1px 3px rgba(15, 32, 68, 0.08), 0 1px 2px rgba(15, 32, 68, 0.06);
shadow-md:  0 4px 12px rgba(15, 32, 68, 0.10), 0 2px 4px rgba(15, 32, 68, 0.06);
shadow-lg:  0 8px 24px rgba(15, 32, 68, 0.12), 0 4px 8px rgba(15, 32, 68, 0.08);
shadow-xl:  0 16px 40px rgba(15, 32, 68, 0.14), 0 8px 16px rgba(15, 32, 68, 0.08);
shadow-floating: 0 20px 48px rgba(15, 32, 68, 0.20);  /* 플로팅 버튼용 */
```

### 4.5 모서리 반경 (Border Radius)

```
radius-sm:  4px   ← 태그, 뱃지, 소형 버튼
radius-md:  8px   ← 기본 버튼, 인풋 필드
radius-lg:  12px  ← 카드, 모달, 드롭다운
radius-xl:  16px  ← 대형 카드, 패널
radius-full: 9999px ← 플로팅 버튼, 아바타
```

## 5. 컴포넌트 명세

### 5.1 요약 카드 (Summary Card)

대시보드 상단에 배치하여 핵심 수치를 한눈에 파악할 수 있게 합니다.

**구조 (아나토미)**

```
┌────────────────────────────────┐
│  [아이콘 24px]  카드 제목       │  ← 헤더 영역 (Navy-100 배경)
├────────────────────────────────┤
│                                │
│   ₩ 23,500,000,000             │  ← 주요 수치 (Numeric-L 서체)
│                                │
│   전월 대비 ▲ 5.2%  [Gold-500] │  ← 변화율 (Body-S)
│                                │
│   마지막 갱신: 2026.03.26      │  ← 날짜 (Caption, Neutral-500)
└────────────────────────────────┘
```

**스펙**

| 속성 | 값 |
|------|-----|
| 최소 너비 | 240px |
| 카드 배경 | White |
| 헤더 배경 | Navy-100 |
| 헤더 패딩 | 16px 20px |
| 본문 패딩 | 24px 20px |
| 보더 | 1px solid Navy-200 |
| 모서리 | radius-lg (12px) |
| 그림자 | shadow-md |
| 아이콘 색상 | Navy-700 |

**상태 변형**

- `default`: 일반 흰색 배경
- `highlight`: 헤더 배경 Gold-100, 보더 Gold-400 (매각가 등 최중요 수치)
- `success`: 헤더 배경 Green-100, 보더 Green-400 (완료된 단계)
- `loading`: Skeleton 애니메이션 (배경 Neutral-100 → Neutral-050 순환)

**접근성**

- `role="region"` + `aria-label="[카드 제목] 요약"`
- 수치에 `aria-label="금액 이십삼억오천만원"` 형태로 읽기 쉬운 설명 제공

### 5.2 파일 업로드 영역 (File Upload Zone)

재무제표, 등기부등본, 세금 서류 등을 업로드하는 영역입니다.

**구조**

```
┌─────────────────────────────────────────┐
│                                         │
│    [업로드 아이콘 48px, Navy-600]         │
│                                         │
│    파일을 이곳에 드래그하거나             │  ← H4 크기 (18px)
│    아래 버튼을 클릭하세요                │
│                                         │
│    허용 형식: PDF, JPG, PNG (최대 20MB) │  ← Body-S (14px, Neutral-500)
│                                         │
│    ┌────────────────────────────────┐   │
│    │   + 파일 선택하기 (클릭)       │   │  ← 보조 버튼
│    └────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

**업로드 후 파일 목록 행**

```
┌──────────────────────────────────────────────────────┐
│  [PDF 아이콘]  재무제표_2025.pdf      2.3MB  [삭제 ×] │
│               ████████████████████░░  80%            │
└──────────────────────────────────────────────────────┘
```

**스펙**

| 속성 | 값 |
|------|-----|
| 드롭존 최소 높이 | 180px |
| 보더 스타일 | 2px dashed Navy-400 |
| 보더 모서리 | radius-xl (16px) |
| 기본 배경 | Navy-050 |
| 드래그 오버 배경 | Navy-100 |
| 드래그 오버 보더 | 2px dashed Navy-700 |
| 파일 행 높이 | 64px (터치 타겟 준수) |

**상태**

- `idle`: 기본 안내 텍스트 표시

- `uploading`: 진행 바 (Green-200) 표시
- `complete`: 초록 체크 아이콘 + 파일명

**접근성**

- 실제 `<input type="file">` 요소를 숨기지 않고 시각적으로만 스타일링
- `aria-label="서류 파일 업로드 영역"` 적용
- 드래그 불가 환경을 위해 반드시 클릭 방식의 대안 제공

## 7. 반응형 전략

### 7.1 브레이크포인트 정의

| 이름 | 범위 | 주요 기기 | 레이아웃 전략 |
|------|------|----------|-------------|
| `desktop-xl` | 1440px 이상 | 대형 모니터 | 12컬럼, 최대 너비 1440px |
| `desktop` | 1280px ~ 1439px | 일반 노트북/PC | 12컬럼, 사이드바 + 메인 |
| `desktop-sm` | 1024px ~ 1279px | 소형 노트북 | 12컬럼, 사이드바 축소 |
| `tablet` | 768px ~ 1023px | 아이패드 | 8컬럼, 사이드바 숨김 (토글) |
| `mobile` | 767px 이하 | 스마트폰 | 4컬럼, 하단 탭 네비게이션 |

> **전략: 데스크톱 우선 (Desktop First)**
> 주 사용자(60대+ CEO)는 데스크톱/노트북 중심으로 업무를 처리합니다. 모바일은 최소 기능만 지원하되 접근성은 동일하게 유지합니다.

### 7.2 레이아웃 변환 규칙

**네비게이션**

```
데스크톱: 좌측 고정 사이드바 (240px 너비)
태블릿:   상단 접이식 헤더 메뉴 (햄버거 버튼)
모바일:   하단 고정 탭바 (최대 4개 메뉴)
```

**데이터 테이블**

```
데스크톱:  전체 열 표시
태블릿:   가로 스크롤 (sticky 첫 열)
모바일:   카드형으로 변환 (행 → 카드 1개)
```

**칸반보드**

```
데스크톱:  4열 칸반 (단계별 컬럼)
태블릿:   2열 칸반 (단계 토글 탭 추가)
모바일:   1열 목록 (단계 필터 드롭다운)
```

**상담 요청 폼**

```
데스크톱/태블릿:  모달 팝업 (560px 최대 너비)
모바일:          전체 화면 시트 (bottom sheet)
```

## 8. 접근성 가이드라인

### 8.1 준수 기준

**목표: WCAG 2.1 AA 수준 (일부 항목 AAA)**

| 카테고리 | 기준 | 비고 |
|---------|------|------|
| 색상 대비 (본문) | 4.5:1 이상 (AA) | 실제 구현: 8:1 이상 권장 |
| 색상 대비 (대형 텍스트 24px+) | 3:1 이상 (AA) | |
| 터치/클릭 타겟 | 44x44px 이상 (AA) | 승계브릿지 기준: 56x56px |
| 포커스 인디케이터 | 3:1 대비 이상 | 3px solid Navy-600 외곽선 |
| 키보드 탐색 | 전체 기능 키보드 접근 가능 | Tab, Enter, Space, ESC, 화살표 |
| 스크린 리더 | ARIA 레이블 완비 | NVDA, JAWS, macOS VoiceOver 테스트 |
| 움직임 | 자동 재생 콘텐츠 없음 | 로딩 스피너 제외 |
| 세션 타임아웃 | 최소 20분 연장 가능 알림 | 또는 비활성화 옵션 |

### 8.2 시각 접근성

**글꼴 크기 확대 지원**

- 브라우저 200% 확대 시에도 가로 스크롤 없이 콘텐츠 표시
- `rem` 단위 사용 필수 (px 고정 금지, 아이콘 제외)
- 사용자 OS 글꼴 크기 설정 반영

**색맹/색약 대응**

- 상태 표현 시 색상 + 아이콘/텍스트 동시 사용 필수
- 빨강-초록만으로 구분하는 디자인 금지 (예: 체크리스트 완료/미완료)
- 색상 대비 시뮬레이션 도구 검수 필수: Figma Able 플러그인

### 8.3 인터랙션 접근성

**키보드 네비게이션 순서**

```
로고 → 메인 메뉴 → 서브 메뉴 → 메인 콘텐츠 영역 → 카드/테이블 → 액션 버튼 → 푸터
```

- 포커스 순서는 시각적 레이아웃 순서와 일치
- `tabindex="-1"` 남용 금지 (포커스 트랩 방지)
- 모달 열릴 시 포커스 모달 내부로 이동, 닫힐 시 트리거 버튼으로 복귀

**시맨틱 HTML 필수 사용**

```html
<!-- 금지 -->
<div class="button">상담 신청</div>

<!-- 권장 -->
<button type="button">상담 신청</button>
```

```html
<!-- 구조 예시 -->
<main>
  <section aria-labelledby="dashboard-title">
    <h2 id="dashboard-title">M&A 진행 현황</h2>
    ...
  </section>
</main>
```

### 8.4 인지 접근성 (60대+ 특화)

| 항목 | 가이드라인 |
|------|----------|
| 오류 메시지 | 무엇이 잘못됐는지 + 어떻게 고쳐야 하는지 명확히 기재 |
| 확인 단계 | 중요한 행동(서류 제출, 상담 신청) 전 확인 단계 필수 |
| 진행 표시 | 여러 단계 폼에는 "3단계 중 2단계" 형태의 진행 표시 |
| 도움말 | 전문 용어 옆 `?` 아이콘으로 툴팁 설명 제공 |
| 되돌리기 | 실수로 삭제한 경우 30초 이내 취소(Undo) 가능 |
| 입력 도움 | 전화번호, 사업자 번호 등 형식 자동 포맷팅 |
| 세션 유지 | 폼 작성 중 세션 만료 시 임시 저장 후 재로그인 안내 |
