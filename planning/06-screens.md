# 화면 명세서 (Screen Specification)

**프로젝트**: 기업승계형 M&A 플랫폼 "승계브릿지"
**문서 버전**: v1.0
**작성일**: 2026-03-26
**목적**: /screen-spec 스킬의 입력 데이터로 활용

---

## 개요

총 9개의 화면으로 구성됩니다. 인증이 필요한 화면(대시보드 이후)은 로그인 세션이 없을 경우 `/auth`로 리다이렉트합니다.

### 화면 목록

| # | 화면명 | URL | 인증 필요 |
|---|--------|-----|----------|
| 1 | 랜딩 페이지 | `/` | 불필요 |
| 2 | 회원가입/로그인 | `/auth` | 불필요 |
| 3 | 대시보드 | `/dashboard` | 필요 |
| 4 | 재무제표 업로드 | `/valuation/upload` | 필요 |
| 5 | AI 추출/검토 | `/valuation/review` | 필요 |
| 6 | 예상가치 결과 | `/valuation/result` | 필요 |
| 7 | 세금 시뮬레이션 | `/tax-simulation` | 필요 |
| 8 | 매각 로드맵 | `/roadmap` | 필요 |
| 9 | 전문가 상담 요청 | `/consultation` | 필요 |

## Screen 1: 랜딩 페이지

| 항목 | 내용 |
|------|------|
| **화면명** | 랜딩 페이지 |
| **URL** | `/` |
| **인증 필요** | 불필요 |

### 진입점
- 직접 URL 입력
- 검색엔진 검색 결과 클릭
- 외부 링크, 광고 배너

### 주요 요소

| 요소 | 설명 |
|------|------|
| 히어로 섹션 | 서비스 핵심 가치를 담은 헤드라인 + 회원가입/체험하기 CTA 버튼 |
| 서비스 소개 3단계 | "가치 산정 → 세금 비교 → 로드맵" 3단계 프로세스 카드 |
| 신뢰 지표 | 거래 완료 건수, 평균 기업가치 절감률, 사용자 수 등 통계 숫자 |
| FAQ | 서비스 관련 자주 묻는 질문 및 답변 아코디언 |
| 푸터 | 회사 정보, 이용약관, 개인정보처리방침, 고객센터 링크 |
| 플로팅 상담 버튼 | 우측 하단 고정 "상담 요청" 버튼 |

### 데이터 요구

| 데이터 | 출처 | 비고 |
|--------|------|------|
| 통계 수치 | 운영팀 입력 / 관리자 설정 | 거래 건수, 평균 절세 금액 등 |
| FAQ 목록 | 운영팀 입력 / CMS | 질문/답변 텍스트 |

### 액션

| 액션 | 트리거 | 동작 |
|------|--------|------|
| 회원가입 시작 | 히어로 CTA 버튼 클릭 | `/auth`로 이동 |
| 로그인 | 네비게이션 "로그인" 클릭 | `/auth`로 이동 |
| 상담 요청 | 플로팅 버튼 클릭 | `/consultation`으로 이동 |
| FAQ 펼치기/접기 | 질문 항목 클릭 | 인라인 답변 토글 |

### 이동 경로

```
랜딩 페이지 (/)
  ├── CTA 클릭 → /auth (회원가입)
  ├── 로그인 클릭 → /auth (로그인)
  └── 플로팅 상담 버튼 → /consultation
```

## Screen 2: 회원가입/로그인

| 항목 | 내용 |
|------|------|
| **화면명** | 회원가입/로그인 |
| **URL** | `/auth` |
| **인증 필요** | 불필요 (이미 로그인된 경우 `/dashboard`로 리다이렉트) |

### 진입점
- 랜딩 페이지 CTA 버튼 클릭
- 랜딩 페이지 네비게이션 "로그인" 클릭
- 인증이 필요한 화면 접근 시 자동 리다이렉트

### 주요 요소

| 요소 | 설명 |
|------|------|
| 탭 전환 | "회원가입" / "로그인" 탭으로 폼 전환 |
| 이메일 입력 필드 | 이메일 형식 유효성 검사 포함 |
| 비밀번호 입력 필드 | 최소 8자, 표시/숨김 토글 버튼 |
| 소셜 로그인 (구글) | Google OAuth 버튼 |
| 약관 동의 체크박스 | 이용약관 및 개인정보처리방침 동의 (회원가입 시) |
| 비밀번호 찾기 링크 | 로그인 탭에서 표시 |

### 데이터 요구

| 데이터 | 출처 | 비고 |
|--------|------|------|
| 사용자 이메일 | 사용자 입력 | 중복 확인 필요 |
| 비밀번호 | 사용자 입력 | 해시 처리 후 저장 |
| 구글 OAuth 토큰 | Google OAuth 2.0 API | 소셜 로그인 시 |
| 약관 동의 여부 | 사용자 입력 | 회원가입 필수값 |

### 액션

| 액션 | 트리거 | 동작 |
|------|--------|------|
| 회원가입 제출 | "회원가입" 버튼 클릭 | 유효성 검사 → API 호출 → 대시보드 이동 |
| 로그인 제출 | "로그인" 버튼 클릭 | 유효성 검사 → API 호출 → 대시보드 이동 |
| 구글 로그인 | Google 버튼 클릭 | Google OAuth 팝업 → 인증 → 대시보드 이동 |
| 탭 전환 | 탭 클릭 | 폼 전환 (입력값 초기화) |
| 비밀번호 찾기 | 링크 클릭 | 비밀번호 재설정 이메일 발송 모달 |

### 이동 경로

```
회원가입/로그인 (/auth)
  └── 인증 성공 → /dashboard
```

## Screen 3: 대시보드

| 항목 | 내용 |
|------|------|
| **화면명** | 대시보드 |
| **URL** | `/dashboard` |
| **인증 필요** | 필요 |

### 진입점
- 로그인/회원가입 완료 후 자동 이동
- 사이드바 네비게이션 "대시보드" 클릭
- 브라우저 직접 URL 접근 (인증 세션 유효 시)

### 주요 요소

| 요소 | 설명 |
|------|------|
| 요약 카드 1 - 기업가치 | 최근 산정된 예상 기업가치 범위 표시, 미완료 시 "산정 시작" 상태 |
| 요약 카드 2 - 세금 | 최적 시나리오 예상 세액 표시, 미완료 시 "시뮬레이션 시작" 상태 |
| 요약 카드 3 - 로드맵 진행률 | 현재 완료된 Phase 및 전체 진행률 프로그레스바 |
| 요약 카드 4 - 상담 상태 | 최근 상담 요청 상태 (접수중/검토중/완료), 미요청 시 "상담 요청" |
| 최근 활동 | 사용자의 최근 작업 이력 타임라인 (업로드, 검토 완료 등) |
| 빠른 액션 버튼 | "기업가치 산정", "세금 시뮬레이션", "로드맵 보기", "상담 요청" |
| 플로팅 상담 버튼 | 우측 하단 고정 버튼 |

### 데이터 요구

| 데이터 | 출처 | 비고 |
|--------|------|------|
| 사용자 기본 정보 | 사용자 DB | 이름, 가입일 |
| 기업가치 산정 결과 | 밸류에이션 서비스 | 최근 산정 결과 |
| 세금 시뮬레이션 결과 | 세금 시뮬레이션 서비스 | 최적 시나리오 요약 |
| 로드맵 진행률 | 로드맵 서비스 | Phase별 완료 체크리스트 기준 |
| 상담 요청 상태 | 상담 관리 서비스 | 최근 상담 건의 상태 |
| 최근 활동 이력 | 활동 로그 서비스 | 최근 5~10건 |

### 액션

| 액션 | 트리거 | 동작 |
|------|--------|------|
| 기업가치 카드 클릭 | 카드 클릭 | `/valuation/upload` 또는 `/valuation/result` 이동 |
| 세금 카드 클릭 | 카드 클릭 | `/tax-simulation` 이동 |
| 로드맵 카드 클릭 | 카드 클릭 | `/roadmap` 이동 |
| 상담 카드 클릭 | 카드 클릭 | `/consultation` 이동 |
| 빠른 액션 버튼 클릭 | 버튼 클릭 | 해당 화면으로 이동 |

### 이동 경로

```
대시보드 (/dashboard)
  ├── 기업가치 카드 → /valuation/upload (미완료 시)
  ├── 기업가치 카드 → /valuation/result (완료 시)
  ├── 세금 카드 → /tax-simulation
  ├── 로드맵 카드 → /roadmap
  ├── 상담 카드 → /consultation
  └── 플로팅 상담 버튼 → /consultation
```

## Screen 4: 재무제표 업로드

| 항목 | 내용 |
|------|------|
| **화면명** | 재무제표 업로드 |
| **URL** | `/valuation/upload` |
| **인증 필요** | 필요 |

### 진입점
- 대시보드 "기업가치 산정" 카드 클릭
- 대시보드 빠른 액션 "기업가치 산정" 버튼
- 사이드바 네비게이션

### 주요 요소

| 요소 | 설명 |
|------|------|
| 드래그앤드롭 업로드 영역 | 파일을 끌어다 놓거나 클릭하여 파일 선택 |
| 지원 포맷 안내 | PDF, Excel(.xlsx, .xls) 지원 명시, 최대 파일 크기 안내 |
| 업로드 진행률 표시 | 파일 업로드 중 프로그레스바 및 퍼센트 표시 |
| 업로드된 파일 목록 | 업로드 완료된 파일 이름, 크기, 삭제 버튼 |
| 업로드 가이드 | 어떤 서류를 업로드해야 하는지 설명 (최근 3년 결산서 권장) |
| 플로팅 상담 버튼 | 우측 하단 고정 버튼 |

### 데이터 요구

| 데이터 | 출처 | 비고 |
|--------|------|------|
| 업로드 파일 | 사용자 로컬 파일 | PDF 또는 Excel 형식 |
| 파일 업로드 상태 | 파일 업로드 API | 진행률 실시간 수신 |

### 액션

| 액션 | 트리거 | 동작 |
|------|--------|------|
| 파일 드롭 | 드래그앤드롭 | 업로드 영역에 파일 추가 |
| 파일 선택 | 업로드 영역 클릭 | OS 파일 선택 다이얼로그 열기 |
| 파일 업로드 | 파일 선택 완료 | 서버로 파일 전송 및 진행률 표시 |
| 파일 삭제 | 삭제 버튼 클릭 | 업로드 목록에서 제거 |
| 분석 시작 | "AI 추출 시작" 버튼 클릭 | AI 분석 요청 → `/valuation/review` 이동 |
| 상담 요청 | 플로팅 버튼 클릭 | `/consultation` 이동 |

### 이동 경로

```
재무제표 업로드 (/valuation/upload)
  ├── 업로드 완료 + 분석 시작 → /valuation/review
  ├── 뒤로가기 → /dashboard
  └── 플로팅 상담 버튼 → /consultation
```

## Screen 5: AI 추출/검토

| 항목 | 내용 |
|------|------|
| **화면명** | AI 추출/검토 |
| **URL** | `/valuation/review` |
| **인증 필요** | 필요 |

### 진입점
- 재무제표 업로드 완료 후 자동 이동 (AI 분석 완료 시)

### 주요 요소

| 요소 | 설명 |
|------|------|
| AI 추출 재무 수치 테이블 | 매출액, 영업이익, EBITDA, 당기순이익 등 연도별 추출 결과 테이블 |
| 수치 편집 기능 | 각 셀을 클릭하여 수치 직접 수정 가능 (AI 오류 수정용) |
| 사적비용 항목 체크 | 오너 급여, 개인차량비, 기타 사적비용 항목별 체크박스 (EBITDA 정상화 반영) |
| 업종 선택 드롭다운 | 멀티플 산정 기준이 되는 업종 카테고리 선택 |
| 추출 신뢰도 표시 | AI가 추출한 각 수치의 신뢰도 레벨 (높음/중간/낮음) 표시 |
| 원본 파일 미리보기 | 업로드한 파일 참조용 사이드 패널 |
| 플로팅 상담 버튼 | 우측 하단 고정 버튼 |

### 데이터 요구

| 데이터 | 출처 | 비고 |
|--------|------|------|
| AI 추출 재무 데이터 | AI 분석 서비스 | 연도별 매출, 영업이익, EBITDA 등 |
| 추출 신뢰도 | AI 분석 서비스 | 항목별 신뢰도 점수 |
| 업종 목록 | 업종 코드 DB | 드롭다운 선택지 |
| 사적비용 카테고리 | 시스템 설정 | 체크박스 항목 목록 |
| 원본 파일 | 파일 스토리지 | 미리보기용 서명된 URL |

### 액션

| 액션 | 트리거 | 동작 |
|------|--------|------|
| 수치 수정 | 셀 클릭 → 수정 | 해당 셀 인라인 편집 활성화 |
| 사적비용 체크 | 체크박스 클릭 | 정상화 EBITDA 실시간 재계산 표시 |
| 업종 선택 | 드롭다운 선택 | 선택된 업종 상태 업데이트 |
| 확인 및 계속 | "가치 산정 보기" 버튼 클릭 | 수정 데이터 저장 → `/valuation/result` 이동 |
| 재업로드 | "파일 다시 업로드" 링크 클릭 | `/valuation/upload` 이동 |
| 상담 요청 | 플로팅 버튼 클릭 | `/consultation` 이동 |

### 이동 경로

```
AI 추출/검토 (/valuation/review)
  ├── 확인 → /valuation/result
  ├── 재업로드 → /valuation/upload
  └── 플로팅 상담 버튼 → /consultation
```

## Screen 6: 예상가치 결과

| 항목 | 내용 |
|------|------|
| **화면명** | 예상가치 결과 |
| **URL** | `/valuation/result` |
| **인증 필요** | 필요 |

### 진입점
- AI 추출/검토 확인 완료 후 자동 이동
- 대시보드 기업가치 카드 클릭 (이전 산정 결과 조회)

### 주요 요소

| 요소 | 설명 |
|------|------|
| EBITDA 정상화 결과 | 사적비용 조정 전/후 EBITDA 비교 표시 |
| 업종별 멀티플 범위 | 선택된 업종의 시장 거래 멀티플 최솟값~최댓값 |
| 예상 기업가치 범위 | 최솟값~최댓값 기업가치 (정상화 EBITDA × 멀티플) |
| 비교 차트 | 멀티플별 기업가치 시각화 (바 차트 또는 범위 차트) |
| 산정 기준 설명 | 멀티플 선택 근거 및 업종 비교 데이터 |
| PDF 저장 버튼 | 결과 리포트 PDF 다운로드 |

## 화면 간 이동 흐름 전체 요약

```
/ (랜딩)
```
